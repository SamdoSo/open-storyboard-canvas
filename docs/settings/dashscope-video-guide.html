视频供应商配置 · v0.1.26+

在 open-storyboard-canvas 中接入 DashScope 通义万相

通过"请求体模板 JSON"和异步轮询配置,把阿里云百炼(DashScope)的通义万相视频生成接口接到画布里。 本教程以 wan3.0-video 模型为例,其他模型路径与字段名基本一致。

前置准备

在开始配置之前,先确认下面三件事都准备好了:

  1. 已经开通了阿里云百炼服务,并拿到了 API Key(形如 sk-xxxxxxxx)。在 阿里云百炼控制台 可以创建。
  2. 拿到了 Workspace ID(工作空间 ID,形如 1966xxxxxxxx)。 路径:百炼控制台右上角 → 工作空间设置。
  3. open-storyboard-canvas 版本 ≥ 0.1.26,确保"请求体模板 JSON"和异步轮询字段都已支持。

Workspace ID 必须直接拼到 baseUrl 里。程序只会自动替换 URL 路径里的 {model} 和 {modelId} 占位符,{WorkspaceId} 不会被替换 —— 否则提交请求时会出现 404。

配置步骤

打开 设置 → 添加供应商。下面每一步对应表单里的一个或多个字段,按顺序填好保存即可。

1

基本信息

在"添加供应商"表单顶部,填写以下字段:

字段 值
服务商名称 DashScope 通义万相(或任意你喜欢的标识)
API 根地址 (baseUrl) https://{WorkspaceId}.cn-beijing.maas.aliyuncs.com
把 {WorkspaceId} 替换成你的实际工作空间 ID,例如 1966xxxxxxxx。
接口路径 (endpointPath) /api/v1/services/aigc/video-generation/video-synthesis
API Key sk-xxxxxxxx(你的百炼 API Key)
模型 ID wan3.0-video(按需替换为通义万相其他视频模型)

API Key 会被自动转换为 Authorization: Bearer {apiKey} 请求头,无需手动配置。

2

附加请求头

DashScope 异步任务必须带 X-DashScope-Async: enable 头:

extraHeaders (JSON) 
{ "X-DashScope-Async": "enable" }
3

请求体模板 JSON(高优先级)

这是最关键的一步。DashScope 的请求体结构比较特殊(顶层是 input 和 parameters 两个嵌套对象),程序默认按扁平字段拼装,所以必须用"请求体模板 JSON"覆盖。

找到"自定义请求体映射"区域下方折叠的 请求体模板 JSON 文本框,填入:

videoRequestBodyTemplate (JSON) 
{
  "model": "{model}",
  "input": {
    "prompt": "{prompt}",
    "media": [
      { "type": "file", "url": "{firstImage}" }
    ]
  },
  "parameters": {
    "resolution": "{extra.resolution}",
    "ratio": "{extra.ratio}",
    "duration": "{duration}",
    "prompt_extend": true
  }
}

模板变量说明:

  • {model}、{prompt}、{firstImage} 来自画布节点的标准变量
  • {duration} 来自节点的 extra_params.duration
  • {extra.resolution} / {extra.ratio} 走 extra 通道,需要节点面板额外配置
  • prompt_extend 在这里写死为 true,因为模板引擎对 boolean 只能输出字符串,固定值最稳
4

异步轮询字段(必填)

DashScope 提交后立刻返回 { "output": { "task_id": "...", "task_status": "PENDING" } },程序需要主动去查任务结果。 填好下面这些字段,程序才能正确识别"成功 / 失败"并拿到视频 URL。

关键提醒:DashScope 的成功响应里视频 URL 在 output.video_url,不在顶层。所以"结果视频路径 JSON"必须写 ["output.video_url", ...] 这种点路径,不能写 ["video_url"](那样永远找不到)。

字段 填写值
videoTaskIdPath output.task_id
videoStatusEndpointPath /api/v1/tasks/{taskId}
videoStatusMethod GET
videoStatusPath output.task_status
videoPendingValues ["PENDING", "RUNNING"]
videoSuccessValues ["SUCCEEDED"]
videoFailedValues ["FAILED", "CANCELED", "UNKNOWN"]
responseVideoPath output.video_url(UI 字段是 JSON 数组,见下方补充)
videoPollIntervalMs 10000(10 秒轮询一次)
videoPollTimeoutMs 1200000(20 分钟超时)

状态值大小写敏感。DashScope 用大写 (PENDING / SUCCEEDED),程序默认是 OpenAI 风格的小写,必须改成大写。

"结果视频路径 JSON" 字段详细说明

这个字段是字符串数组,程序按顺序尝试,找到第一个非空值就用。 每一项都是相对完整轮询响应的点路径(类似 JS 的 obj['a.b[0].c']):

  • . 取子属性
  • [0] 取数组第 N 项
responseVideoPaths (JSON 数组) 
[
  "output.video_url",
  "output.result_url",
  "output.url",
  "data[0].url",
  "data[0].video_url"
]

上面几种形式按出现概率排序。DashScope 标准返回是 output.video_url,所以第一项就是它;后几项是兜底, 兼容部分返回 data 数组的子任务或供应商变体。

5

下拉框选项(durations / aspectRatios / resolutions)

这些字段控制视频节点右侧的属性面板里能选哪些值。点开对应字段的输入框,改成:

字段 建议值
durations ["5", "10"]
aspectRatios ["16:9", "9:16", "1:1"]
resolutions ["480P", "720P", "1080P"](注意是大写 P,跟阿里云一致)
6

保存并测试

点表单底部的"保存"。回到画布,新建一个视频节点,选中模型 wan3.0-video,触发一次生成。

同时打开 开发者工具 → Network 面板,应该看到:

  1. POST /api/v1/services/aigc/video-generation/video-synthesis → 200,返回 output.task_id
  2. GET /api/v1/tasks/{taskId} × N → 200,直到 task_status: SUCCEEDED
  3. 画布上视频节点展示生成的 MP4

如果某一步没出现或状态值不识别,回到上一步对照字段值。

常见问题

❌ 提交后报"响应中未找到视频任务或视频 URL"

错误提示里附带的"响应预览"是提交时的响应(看起来只有 pending + id),不代表 task id 没读到。

真正的诊断方式是:看 Network 面板里有没有 第二个请求(GET /api/v1/tasks/{id})。

  • 没有 → videoStatusEndpointPath 没填或填错了
  • 有但一直 200 + PENDING → 状态值大小写不匹配,或 videoSuccessValues 写错
  • 有但 404 → 状态查询 endpoint 路径不对,对照阿里云文档

❌ URL 路径里的 {WorkspaceId} 没被替换

这是正常行为 —— URL 路径只支持 {model} 自动替换,其它占位符不会被处理。 把 Workspace ID 直接拼进 baseUrl 即可。

❌ boolean 字段(比如 prompt_extend)发出去是字符串 "true"

模板引擎对 boolean 只能输出字符串(被 String() 序列化)。如果上游 API 严格要 JSON boolean:

  • 优先在模板里把这种字段写死(比如 "prompt_extend": true 不带占位符)
  • 或者在节点的 extra_params 里直接控制 —— 把模板改成 "prompt_extend": "{extra.prompt_extend}",节点填字符串

❌ 想用首尾帧,但 media 数组只能传一张

这是当前模板系统的限制 —— {firstImage} 是单值,不能展开成多张图带 role。

临时绕法:把 media 数组从模板里删掉,在 parameters 里加 "img_url": "{firstImage}"(部分 dashscope 端点支持)。彻底解法需要扩展模板引擎支持数组 map。
